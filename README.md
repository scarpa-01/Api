# 🚀 Minha API

API REST simples construída com **FastAPI** (Python). Serve como base para projetos pessoais — fácil de adaptar e reutilizar.

## 📋 O que é isto?

Uma API de exemplo com operações CRUD básicas (criar, listar, consultar e apagar itens). Os dados ficam **em memória** (não persistem entre reinícios).

## 🛠️ Tecnologias

- [Python 3.10+](https://www.python.org/)
- [FastAPI](https://fastapi.tiangolo.com/) — framework web moderno e rápido
- [Uvicorn](https://www.uvicorn.org/) — servidor ASGI
